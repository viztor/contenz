## 2026-05-14 - Semantic Color Highlighting in CLI Output
**Learning:** Terminal output containing structured data or diagnostics can be difficult for users to scan when printed plainly. Key information gets lost in walls of text.
**Action:** Always use semantic color highlighting (via `picocolors`) when printing structured data (e.g., coloring object keys) or error diagnostics to the CLI terminal to distinguish structural keys and critical information from plain text, significantly improving scannability.
