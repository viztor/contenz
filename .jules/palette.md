## 2024-05-24 - Misleading Affordances & Focus Visibility
**Learning:** In the preview dashboard, scoping interactive classes (like `.card:hover` or generic cursors) to static elements creates misleading affordances for users. It is crucial to strictly bind interactive pseudo-classes and cursors to semantically interactive HTML tags (e.g., `a.card` rather than `.card`). Additionally, custom interactive elements often lose default browser outlines due to resets or custom backgrounds, requiring explicit `:focus-visible` styles for keyboard navigation accessibility.
**Action:** When creating or modifying custom UI components (like cards or links), always separate the static visual styling from interactive behaviors. Apply `cursor: pointer` and `:hover` only to interactive variants (like `a` or `button`), and explicitly add `:focus-visible` outlines using the design system's accent color.
