## 2024-06-05 - Missing Semantic States & Empty View Design Flaws
**Learning:** React SPA navigation links inside `@contenz/preview` lacked `aria-current` indicators, and cards/links lacked `:focus-visible` outlines, hiding active state and keyboard navigation cues from screen readers and power users. Additionally, "empty states" in list views merely output raw text instead of utilizing standard visual card structures, confusing users about the application state.
**Action:** Always ensure navigation utilizes `aria-current="page"` conditionally based on the route, explicitly style `:focus-visible` for primary interactive elements, and apply structured "Empty State" UI components (icons + dashed borders + centered text) instead of plain text fallbacks to maintain visual hierarchy.
