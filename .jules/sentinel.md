## 2023-10-27 - Fix Arbitrary Code Execution (ACE) in @contenz/adapter-mdx
**Vulnerability:** The `safeEvalObjectLiteral` function in `@contenz/adapter-mdx` evaluated metadata object literals using `new Function(...)`. This approach allows Arbitrary Code Execution (ACE) if an attacker can control the input string, since the code runs in the global context without any restrictions.
**Learning:** Evaluating untrusted or user-controlled input as code (using `eval` or `new Function`) is extremely dangerous and can lead to full system compromise. Although the metadata is expected to be an object literal, malicious MD/MDX files could exploit this. Additionally, using `node:vm` as a sandbox is unsafe (security theatre) and causes environment regression (breaks browser/edge environments).
**Prevention:** Instead of using `new Function` or `node:vm`, safely parse the object literal without code execution using an AST parser or `json5`. Using `json5.parse` ensures safety and keeps the package environment-agnostic.
