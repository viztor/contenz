## 2024-05-18 - Arbitrary Code Execution in Object Literal Parsing
**Vulnerability:** Arbitrary Code Execution (ACE) via `new Function` when parsing metadata blocks (`export const meta = { ... }`) in `.mdx` files. The previous implementation used `new Function` to execute the block to parse it as an object literal. If an attacker could inject code into these `.mdx` files or if the input is untrusted, it would execute whatever code was injected in the current execution context.
**Learning:** `new Function` or `eval` should never be used to parse JavaScript object literals from untrusted or dynamically provided sources as they allow arbitrary code execution with the full privileges of the Node.js process.
**Prevention:** Use `node:vm`'s `runInNewContext` to safely parse and evaluate dynamic JavaScript or object literals. Always pass an empty context `Object.create(null)` to ensure the executed code has no access to global objects or functions, and set a strict execution `timeout` (e.g., `{ timeout: 100 }`) to prevent Denial of Service (DoS) attacks via infinite loops.
