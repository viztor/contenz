## 2024-07-24 - Avoid dynamic regex in parseFileName
**Learning:** In `@contenz/core`, functions that process files in bulk (like `parseFileName`) are critical hot paths. Avoid instantiating dynamic `RegExp` objects inside these functions. Prefer standard string manipulation or statically compiled regexes to prevent severe performance degradation. When extracting extensions, use `endsWith()` against known extensions rather than `lastIndexOf('.')` to prevent breaking support for multi-dot custom extensions (e.g., `.page.md`).
**Action:** When working on hot paths, especially those involving bulk file processing, ensure that regular expressions are compiled statically outside the function body. If dynamic patterns are required, evaluate if they can be substituted with native string methods like `endsWith()` and `slice()`.
